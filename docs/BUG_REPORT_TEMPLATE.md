# Mẫu ghi nhận lỗi giao diện

| Trường | Nội dung |
|---|---|
| Mã lỗi | BUG-01 |
| Test case liên quan | WEB-01 hoặc MOB-01 |
| Môi trường | Phiên bản app, trình duyệt/thiết bị và hệ điều hành |
| Mức ảnh hưởng | Nghiêm trọng / Cao / Trung bình / Thấp; ghi lý do |
| Tiền điều kiện | Trạng thái trước khi tái hiện |
| Bước tái hiện | Các bước tối thiểu theo thứ tự |
| Kết quả mong đợi | Điều đúng ra phải hiển thị/xảy ra |
| Kết quả thực tế | Điều quan sát được |
| Bằng chứng | Ảnh/log đã ẩn danh, có mã ca và ngày |
| Phân loại ban đầu | Lỗi sản phẩm / môi trường / script / chưa xác định |
