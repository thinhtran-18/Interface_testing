# Mẫu test case giao diện

| Trường | Nội dung |
|---|---|
| Mã ca | WEB-01 hoặc MOB-01 |
| Mục tiêu | Chức năng/điều kiện giao diện cần kiểm tra |
| Nền tảng, phiên bản | Web/trình duyệt hoặc app/thiết bị/hệ điều hành |
| Vai trò | Vai trò tài khoản được cấp phép, không ghi mật khẩu |
| Tiền điều kiện | Trạng thái cần có trước khi chạy |
| Dữ liệu thử | Dữ liệu giả hoặc đã ẩn danh |
| Bước thực hiện | Các thao tác theo thứ tự |
| Kết quả mong đợi | Điều quan sát được sau thao tác |
| Kết quả thực tế | Ghi sau khi chạy, không suy đoán |
| Trạng thái | Chưa chạy / Đạt / Không đạt / Bị chặn |
| Bằng chứng | Tên file ảnh/log đã ẩn danh và ngày chạy |
