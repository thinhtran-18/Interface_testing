# Page Objects cho Web

Đặt lớp biểu diễn trang hoặc thành phần Web ở đây, ví dụ `login_page.py` và `staff_search_page.py`. Page Object chứa bộ chọn phần tử và thao tác trên trang; phép kiểm tra kết quả mong đợi đặt trong `tests/web/`. Chỉ tạo Page Object sau khi nhóm xác nhận giao diện và bộ chọn thực tế.
